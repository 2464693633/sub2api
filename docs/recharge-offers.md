# 充值优惠档位

在「管理后台 → 系统设置 → 支付设置 → 充值优惠档位」添加并保存档位。每档分别填写支付币种、支付金额和最终到账美元余额。例如：

| 支付币种 | 支付金额 | 到账余额（USD） |
| --- | ---: | ---: |
| CNY | 100 | 1100 |
| CNY | 500 | 6000 |

这是固定金额档位：支付金额和币种完全匹配时，使用档位设置的最终到账余额，不再乘基础充值倍率。自填金额也会自动匹配；其他金额仍按原来的基础倍率计算。删除全部档位可关闭活动。

充值页按当前支付方式的币种展示可选档位，并显示实付、手续费和到账余额。档位金额不含手续费；例如手续费为 2.5% 时，100 元档位实付 102.50 元，到账仍为 1100 美元。原有的充值限额和支付通道限制继续生效。

后端根据服务端配置和实际支付通道的币种计算到账金额，客户端只提交支付金额。创建订单时会保存最终到账余额；后续调整或删除活动不影响已有订单的入账和退款。重复支付回调使用现有幂等入账流程。

配置存储在现有 settings 表的 `BALANCE_RECHARGE_TIERS`，不需要数据库迁移。管理支付 API 的字段为 `balance_recharge_tiers`，系统设置 API 的字段为 `payment_balance_recharge_tiers`：

```json
[
  { "amount": 100, "credit_amount": 1100, "currency": "CNY" }
]
```

金额必须大于零，最多两位小数；日元等无小数币种的支付金额必须为整数。同币种不能重复配置相同支付金额，最多 50 档。接口更新时省略字段保留原配置，传空数组清除档位。功能默认不配置任何活动，添加后的草稿须由管理员保存才生效。
